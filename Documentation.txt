The code has two parts: 
-> The first part includes an 'initial load' type that is used to handle all the old, unlogged alerts.
-> The second part contains a function that will be called repeatedly to log any processes running longer than necessary.
In the first part, we create lists that will store all the PIDs, both for the started processes and the completed ones, 
followed by checking which processes are completed in order to calculate the time difference. The unfinished processes 
will be handled in the second part.
In the second part, we have the function that checks the processes, and if we encounter a process of type 'END,' 
we will remove the PID of the process that was stored under 'START' from the dictionary.
